# BOOTHFORGE AI

Phase 1 prototype: responsive booth brief builder, three conceptual zoning alternatives, browser-local project persistence, and a CAD-ready JSON export.

## Run locally

Requires Node.js 20+.

```bash
npm install
npm run dev
```

## Current scope

- React + TypeScript + Vite responsive interface
- Booth dimensions and customer requirements
- Three alternative **schematic** zoning layouts
- Local storage and JSON export

**Not yet implemented:** AI-generated 3D renders, dimensioned 2D engineering drawings, FreeCAD integration, accounts, or cloud storage. Concepts are not construction-ready.

## Security

This is a public repository. Never commit OpenAI keys, passwords, or confidential client information.
