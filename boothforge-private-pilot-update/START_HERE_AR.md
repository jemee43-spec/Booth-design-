# BOOTHFORGE AI — إصلاح فتح الشاشة البيضاء

1. فك ضغط هذه النسخة كاملةً إلى مجلد جديد.
2. شغّل START_BOOTHFORGE_WINDOWS.cmd الموجود بجانب هذا الملف.
3. انتظر تجهيز المكتبات؛ سيفتح التطبيق تلقائيًا في المتصفح. اترك نافذة التشغيل مفتوحة.

لا تفتح ملفات index.html القديمة كأنها التطبيق. التطبيق يحتاج خادمي Next.js وFastAPI. صفحة OPEN_BOOTHFORGE.html تقدم شرح التشغيل دون خادم. التشغيل الأول يحتاج Python 3.11+ وNode.js 22+ واتصال الإنترنت لتنزيل المكتبات. لا يحتاج رصيد API، ولم يتم استخدام المفاتيح.

تم اختبار مشغّل Python محليًا: ظهرت الصفحة واستجابت قائمة المشاريع. ملف CMD مخصّص لويندوز ولم يتم تشغيله على جهاز Windows داخل بيئة الاختبار.

main وملفات المشروع الأصلي محفوظة دون تغيير؛ الإصلاحات في فرع محلي منفصل، ولم تُرفع لأن اتصال GitHub رفض الكتابة بخطأ 403. لا يوجد نشر على الإنترنت أو أي إجراء مدفوع.

المجلد Booth-design-private-pilot يحتوي النسخة النظيفة الكاملة. ملف BOOTHFORGE_AI_Private_Pilot.patch يحتوي الإصلاحات مقارنة بالأصل. اقرأ README.md وتقرير deploy/TEST_REPORT.md داخل boothforge-ai للمزيد. اجتازت النسخة 17 اختبار API و4 اختبارات حماية و8 اختبارات متصفح و38 فحص اتصال. توليد الصور وCAD ما زالا غير مفعّلين.

إذا بقيت شاشة بيضاء بعد التشغيل، أرسل عنوان الصفحة من شريط المتصفح مع رسالة الخطأ في نافذة التشغيل. لا ترسل ملفات مفاتيح أو رموزًا سرية.

تحديث التشغيل: تم استبدال uvicorn[standard] بـ uvicorn في requirements.txt؛ أكد المستخدم نجاح التشغيل على Windows. النسخة الحالية تستهدف الفرع boothforge-development. محاولة إنشاء الفرع في GitHub ما زالت ترفض الكتابة بخطأ 403، ولم يتم الرفع.
